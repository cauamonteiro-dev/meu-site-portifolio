# Portfólio Pessoal — Cauã Monteiro

Portfólio web pessoal desenvolvido como atividade prática de desenvolvimento web, utilizando HTML, CSS, JavaScript, GitHub e GitHub Pages.

O projeto tem como objetivo apresentar minha trajetória acadêmica, meus conhecimentos em tecnologia, projetos desenvolvidos e interesses profissionais de forma simples, organizada e visualmente profissional.

---

## 🎯 Objetivo

Criar uma página web de apresentação acadêmica e profissional que possa ser utilizada para apresentar minha trajetória na área de tecnologia a recrutadores, profissionais da área e outras pessoas interessadas em conhecer meu trabalho.

O projeto também tem como finalidade aplicar, na prática, conceitos fundamentais de desenvolvimento web e utilização de ferramentas de versionamento e publicação.

---

## 🛠️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando tecnologias fundamentais para desenvolvimento web:

* **HTML5** — estruturação do conteúdo;
* **CSS3** — estilização, layout e responsividade;
* **JavaScript** — interatividade e funcionalidades da página;
* **Git** — controle de versão;
* **GitHub** — armazenamento e versionamento do projeto;
* **GitHub Pages** — publicação do site na internet.

## 💻 Funcionalidades

O projeto possui funcionalidades implementadas com JavaScript para demonstrar interatividade.

### Menu responsivo

Em dispositivos menores, o menu principal é transformado em um menu compacto que pode ser aberto e fechado pelo usuário.

### Modo claro e escuro

O usuário pode alternar entre os temas claro e escuro através do botão localizado no cabeçalho da página.

### Formulário de contato

A página possui um formulário visual para preenchimento de nome, e-mail e mensagem.

Atualmente, o formulário possui comportamento demonstrativo e apresenta uma mensagem ao usuário após o envio.

### Ano automático

O ano exibido no rodapé é preenchido automaticamente através do JavaScript, evitando a necessidade de atualizá-lo manualmente.

## 🚀 Publicação

O projeto pode ser publicado gratuitamente utilizando o **GitHub Pages**.

Após o projeto ser enviado para um repositório no GitHub, o GitHub Pages pode ser configurado para utilizar os arquivos do repositório como página pública.

A aplicação poderá então ser acessada através de uma URL no formato:

```text
https://seuusuario.github.io/nome-do-repositorio/
```
